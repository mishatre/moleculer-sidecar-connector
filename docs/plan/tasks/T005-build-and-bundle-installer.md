## Context and verification

Use direct `vrunner compileexttocfe` and `vrunner compileepf`, resolving final
arguments from installed help. Generated output stays under `build/`; use
`/workspace/build/ib` only where the runner requires the authorized disposable
target. Do not use the absent Autumn executable, mixed-platform VS Code commands,
or `--updatedb`. Verify clean builds, matching versions/hashes, embedded bytes,
and the draft release before publication.

Implementation path for the initial `0.2.0-beta.4` release:

1. Normalize connector metadata to `0.2.0-beta.4` and validate it as canonical
   SemVer before running 1C tooling.
2. Build the connector from `/workspace`:

   ```bash
   vrunner compileexttocfe \
     --src ./src/cfe/MoleculerSidecarConnector \
     --out ./build/release/MoleculerSidecarConnector-v0.2.0-beta.4.cfe \
     --ibcmd --ibconnection /F./build/ib --v8version 8.3 \
     --root /workspace --ordinaryapp -1 --nocacheuse
   ```

3. Copy installer source to `build/staging/installer`, replace the staged current-
   connector template binary with the newly built CFE, and leave generated bytes
   out of the source tree.
4. Build the staged installer:

   ```bash
   vrunner compileepf build/staging/installer build/release \
     --ibconnection /F./build/ib --v8version 8.3 --root /workspace \
     --ordinaryapp -1 --nocacheuse
   ```

5. Rename the output to
   `MoleculerSidecarConnectorInstaller-v0.2.0-beta.4.epf`, verify the embedded
   CFE bytes/version, generate `SHA256SUMS.txt`, and write release notes containing
   the source revision and tool versions.
6. Repeat from a clean release/staging directory and require identical hashes or
   document and remove any nondeterministic input before acceptance.

## Delivery and authority

The task delivers reviewed build/source changes plus a local reviewable draft-
release directory under `build/release`. No GitHub CLI or authenticated release
tool is currently available in the container. GitHub draft creation and final
publication remain delivery actions after an authorized tool/account is available.

## Stop conditions

Stop if the connector version is not canonical SemVer, the runner would require
`--updatedb`, the build modifies a consumer infobase, generated CFE bytes enter a
source-review diff, or the staged/bundled/released connector hashes disagree.
